📖 درباره پروژه

پکیج Pure Captcha یک راهکار کاملاً مستقل و سبک برای تولید تصاویر کپچای امن در PHP است. این پکیج منحصراً از اکستنشن داخلی GD در PHP استفاده می‌کند و به هیچ سرویس خارجی، کدهای سنگین جاوااسکریپت یا کلیدهای API نیاز ندارد.

✨ امکانات اصلی پکیج

  • 🎨 رابط کاربری زیبا: طراحی مدرن با استفاده از پس‌زمینه‌های گرادیانت شیک و افکت سایه.
  • 🔧 کاملاً قابل تنظیم: امکان تغییر تعداد کاراکتر، ابعاد کادر، فونت‌ها، رنگ‌ها و میزان نویز محیطی.
  • 🛡️ ۵ سطح سختی هوشمند: تنظیم سختی ساختار تصویر از سطح معمولی low تا سطح فوق پیشرفته nightmare.
  • 👻 کاراکترهای شبح (Ghost): تولید حروف کمرنگ و جعلی در پس‌زمینه برای مسدودسازی کامپایلر ربات‌ها.
  • 🌊 اعوجاج موجی شکل: تاب دادن به شکل کاراکترها به صورت سینوسی برای شکست دادن انواع الگوریتم‌های هوش مصنوعی تصویرخوان (OCR).
  • 🌐 پشتیبانی از چندزبانه: بومی‌سازی ساختاری یکپارچه برای زبان‌های فارسی (fa) و انگلیسی (en).
  • 🔄 بارگذاری مجدد (Refresh): دکمه تعویض آنی بر پایه فرآیندهای AJAX به همراه انیمیشن چرخشی مدرن.

📥 روش نصب

نصب آسان پکیج با استفاده از مدیریت وابستگی Composer:

composer require aminarjmand/pure-captcha

🚀 شروع سریع در ۳ مرحله

مرحله ۱: ساخت فایل رندر تصویر

فایلی به نام captcha_image.php بسازید:

<?php
require 'vendor/autoload.php';
use AminArjmand\PureCaptcha\Captcha;

Captcha::renderImage();

مرحله ۲: قرار دادن کدهای کپچا در فرم

<!-- تزریق کدهای HTML در فرم ورودی اطلاعات -->
<form method="POST" action="submit.php">
    <input type="text" name="name" placeholder="نام شما">

    <!-- نمایش ویجت کپچا -->
    <?php echo Captcha::html(); ?>

    <button type="submit">ارسال</button>
</form>

مرحله ۳: بررسی و اعتبارسنجی

در فایل submit.php کد وارد شده را بررسی کنید:

if (Captcha::validate($_POST['captcha'])) {
    echo "✅ کد امنیتی صحیح است!";
} else {
    echo "❌ کد امنیتی اشتباه است.";
}

📖 About Pure Captcha

Pure Captcha is a pure, standalone PHP package that focuses on generating highly secure visual tokens without any mandatory external third-party dependencies. Powered strictly by PHP's local GD library extensions.

✨ Feature Highlights

  • 🎨 Polished Presentation UI: Modern form component aesthetics carrying smooth color gradients and subtle box styling shadows.
  • 🔧 Deep Parameter Customization: Total runtime modifications for custom string length, dimensional parameters, font matrices, and ambient noises.
  • 🛡️ 5 Difficulty Environments: Scale security layers smoothly ranging from lightweight low up to maximum brute-force protection nightmare.
  • 👻 Ghost Character Modules: Overlays randomized semi-transparent decoy text layers onto canvas planes to effectively blind scanner bots.
  • Wave distortion grids, zero third-party JavaScript tracking, full PSR-4 compatibility.

📥 Installation

Incorporate the package instantly inside any modern web framework via Composer:

composer require aminarjmand/pure-captcha

🚀 Fast Setups

1. Target Endpoint Wrapper

Create an independent rendering instance named captcha_image.php:

<?php
require 'vendor/autoload.php';
Captcha::renderImage();

2. Inject Form Framework Markup

<form method="POST" action="submit.php">
    <?php echo Captcha::html(); ?>
    <button type="submit">Submit</button>
</form>
